# Screenshots

The README's Demo section references three images. Save your Telegram screenshots
here with these exact filenames so they render:

| Filename | What to capture |
|----------|-----------------|
| `auto-logged-applications.png` | The run of "🆕 Logged application — … (auto)" messages |
| `job-pipeline-digest.png` | The "📊 Job pipeline — Active: N" digest + a rejection/interview alert |
| `morning-briefing.png` | The energy-sorted morning briefing (High / Medium / Low) |

Tip: crop out anything you don't want public. The screenshots already use only
company names from your real (public) job search — no secrets — but double-check
before committing.
